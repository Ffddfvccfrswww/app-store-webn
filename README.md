# ZARKOR — במה קולנועית לאפליקציות

אתר לפרסום אפליקציות בעיצוב קולנועי בתלת־ממד. מפתחי אפליקציות משלמים **דמי מנוי חודשיים** כדי שהאפליקציה שלהם תוצג באתר — וזו ההכנסה החודשית שלך.

> **חשוב:** "ZARKOR" (זרקור) הוא שם עבודה בלבד. לפני עלייה לאוויר יש לבדוק שהשם פנוי (סימן מסחר ודומיין) או להחליף אותו בשורה אחת בקובץ ההגדרות.

## 2. מה חייבים למלא לפני עלייה לאוויר

כל ההגדרות נמצאות ב**קובץ אחד**: `site.config.js` (קובץ ההגדרות). יש בו הסברים בעברית ליד כל שדה.

| שדה | מה למלא |
|---|---|
| `brand.name` (שם המותג) | שם האתר |
| `siteUrl` (כתובת האתר) | הכתובת המלאה, למשל `https://www.example.com` |
| `operator` (מפעיל האתר) | שם משפטי, כתובת, מדינה, מספר עוסק, הדין החל ומקום השיפוט |
| `contact.email` (דוא"ל ליצירת קשר) | כתובת **ציבורית** — היא תופיע באתר. מומלץ לפתוח תיבה ייעודית ולא להשתמש בתיבה הפרטית |
| `plans` (מסלולים) | המחירים, וקישור התשלום (`checkoutUrl`) של כל מסלול |

אחרי כל שינוי מריצים:

```
npm run build       (בונה מחדש את האתר לתוך התיקייה docs)
npm run preflight   (בדיקת מוכנות — מדפיס בעברית מה עוד חסר)
```

**אפשר פשוט לבקש מ-Claude**: "תעדכן את ההגדרות: השם הוא…, הדוא"ל הוא…, קישורי התשלום הם…" — והוא יעשה את כל זה.

## 3. איך מרוויחים כסף

1. **פותחים חשבון אצל ספק תשלומים** שתומך במנויים חודשיים. מומלץ ספק מסוג Merchant of Record ("מוכר רשמי") כמו Paddle או Lemon Squeezy: הוא גובה את הכסף מכל העולם, מטפל במע"מ ובמסים בכל מדינה, ומעביר לך את התשלום. שניהם מקבלים מוכרים מישראל (נכון לנובמבר 2026 — כדאי לוודא באתר שלהם).
2. **יוצרים אצל הספק שלושה מוצרי מנוי חודשי** במחירים שמופיעים באתר (ברירת מחדל: 19$, 49$, 149$).
3. **מעתיקים את קישור התשלום** של כל מוצר לשדה `checkoutUrl` בקובץ ההגדרות.
4. בהגדרות הספק, קובעים שאחרי תשלום הלקוח יופנה לעמוד `thanks.html` באתר.

**התהליך מול לקוח:** הלקוח ממלא את הטופס ← אתה מקבל את הפרטים בדוא"ל ← בודק שהאפליקציה עומדת בכללים ← הלקוח משלם ← אתה מוסיף את האפליקציה לרשימה (סעיף 5).

המחירים באתר חייבים להיות זהים למחירים אצל ספק התשלומים.

## 4. איך מעלים את האתר לאוויר

האתר המוכן נמצא בתיקייה **`docs`**. זה אתר סטטי (קבצים בלבד, בלי שרת ובלי מסד נתונים), ולכן אפשר לארח אותו בחינם כמעט בכל מקום.

| שירות | מה עושים | כותרות אבטחה מלאות |
|---|---|---|
| **Cloudflare Pages** (מומלץ) | מחברים את המאגר מ-GitHub, ובשדה Build output directory (תיקיית הפלט) כותבים `docs` | כן |
| **Netlify** | מחברים את המאגר. הקובץ `netlify.toml` כבר מגדיר הכול | כן |
| **Vercel** | מחברים את המאגר. הקובץ `vercel.json` כבר מגדיר הכול | כן |
| **GitHub Pages** | Settings (הגדרות) ← Pages ← Branch: `main`, תיקייה: `/docs` | חלקי* |

\* GitHub Pages אינו מאפשר לשלוח כותרות אבטחה מהשרת. האתר עדיין מוגן (מדיניות האבטחה מוטמעת בכל עמוד), אבל לקבלת ציון אבטחה מלא מומלץ אחד משלושת השירותים האחרים.

אחרי שהאתר באוויר: מעדכנים את `siteUrl`, מריצים `npm run build` ודוחפים שוב.

## 5. איך מוסיפים אפליקציה של לקוח

עורכים את הקובץ `src/assets/data/apps.json` (רשימת האפליקציות) ומוסיפים רשומה:

```json
{
  "id": "my-app",
  "name": "My App",
  "tier": "premiere",
  "category": "productivity",
  "glyph": "spark",
  "colors": ["#1f7a6b", "#06201d"],
  "tagline": { "en": "One sentence about the app.", "he": "משפט אחד על האפליקציה." },
  "description": { "en": "A longer description.", "he": "תיאור ארוך יותר." },
  "links": { "ios": "https://apps.apple.com/...", "android": "https://play.google.com/..." }
}
```

- `tier` (מסלול): `screening` / `premiere` / `blockbuster`
- תמונת פוסטר (רשות): שמים קובץ בתיקייה `src/assets/apps/` ומוסיפים `"poster": "assets/apps/my-app.webp"`
- האפליקציות המסומנות `"demo": true` הן **דוגמאות בדויות**. מוחקים אותן כשמגיעים לקוחות אמיתיים.

ואז: `npm run build`. גם את זה אפשר לבקש מ-Claude.

## 7. אבטחה ופרטיות — מה נעשה

- **אפס בקשות לצד שלישי:** הגופנים, הקוד וספריית התלת־ממד מאוחסנים באתר עצמו. אין Google Fonts, אין רכיבי רשתות חברתיות, אין מעקב.
- **אין עוגיות.** האתר שומר במכשיר הגולש שלוש העדפות בלבד (שפה, אנימציה, בחירת פרטיות).
- **מדיניות אבטחת תוכן מחמירה** (Content-Security-Policy): אין קוד מוטמע בעמודים, אין טעינת קוד מאתרים אחרים, וכן Trusted Types.
- **כותרות אבטחה:** HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy ועוד.
- **טופס מוגן:** בדיקת כל שדה, קישורי https בלבד, מלכודת לרובוטים, חסימת שימוש בתוך אתר אחר.
- **סטטיסטיקה כבויה כברירת מחדל,** ונטענת רק אחרי הסכמת הגולש. האתר מכבד אות Global Privacy Control.
- **גילוי נאות:** כל מודעה מסומנת "ממומן", ובתחתית כל עמוד כתוב שהמודעות הן פרסומות בתשלום.
- **נגישות:** נבדק אוטומטית מול WCAG 2.1 AA, כולל כפתור "השהיית אנימציות".

## 8. הערה משפטית — חשוב לקרוא

האתר כולל מסמכים משפטיים מקיפים ונבנה לפי הדרישות המקובלות (GDPR באירופה, CCPA בקליפורניה, חוק הגנת הפרטיות וחוק הגנת הצרכן בישראל).

עם זאת: **אף אתר אינו חסין לחלוטין מתביעות, והמסמכים אינם תחליף לייעוץ משפטי.** לפני ההשקה מומלץ מאוד שעורך/ת דין יעברו על המסמכים ויתאימו אותם לעסק שלך ולמדינה שבה הוא רשום.

בנוסף, באחריותך:
- לבדוק כל אפליקציה לפני פרסומה, לפי "כללי התוכן";
- לטפל בתלונות ובדיווחים שמגיעים לדוא"ל;
- לכבד את מדיניות ההחזרים המתפרסמת באתר (כולל החזר מלא בתוך 14 יום);
- אם הגדרת מספר מקומות מוגבל (`slots`) — לוודא שההגבלה אמיתית.

## 9. בדיקות

```
npm install         (פעם אחת — מתקין את כלי בדיקת הנגישות)
npm test            (מריץ את כל הבדיקות)
```

| חבילה | מה נבדק | מספר בדיקות |
|---|---|---|
| `npm run test:static` (בדיקות קוד) | אבטחה, קישורים שבורים, תרגומים מלאים בכל 10 השפות, רישיונות | 23 |
| `npm run test:e2e` (בדיקות דפדפן) | כל עמוד בדפדפן אמיתי: שגיאות, שפות, פרטיות, טופס, מקלדת, נייד, בלי JavaScript | 40 |
| `npm run test:a11y` (בדיקות נגישות) | סריקת axe-core בכל העמודים, בעברית, בערבית ובנייד | 29 |
| `npm run test:legal` (בדיקות עמידה בחוק) | פרסום הוגן, גילוי נאות, הסכמות, חידוש אוטומטי והחזרים, סימני מסחר, שלמות המסמכים המשפטיים | 28 |

בדיקות הדפדפן דורשות Playwright עם Chromium.

להצגת האתר במחשב: `npm run serve` ואז לפתוח `http://127.0.0.1:4173`.

## 10. מבנה התיקיות

```
site.config.js     קובץ ההגדרות היחיד שעורכים
src/               קוד המקור: עמודים, עיצוב, קוד, תרגומים, רשימת האפליקציות
docs/              האתר המוכן — זו התיקייה שעולה לאוויר (נוצרת אוטומטית, לא עורכים ידנית)
tools/             כלים: בנייה, שרת מקומי, בדיקת מוכנות, יצירת תמונות
tests/             הבדיקות האוטומטיות
```

רכיבי קוד פתוח בשימוש: three.js (רישיון MIT), והגופנים Oswald, Rubik ו-Karantina (רישיון SIL OFL 1.1). נוסחי הרישיונות מצורפים לקבצים.
